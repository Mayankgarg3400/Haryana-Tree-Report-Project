# 🌳 Haryana Tree Plantation RAG Report

An Agentic AI project that generates district-wise Haryana Tree Plantation reports using Retrieval-Augmented Generation (RAG).

## Features

- PDF Parsing
- Excel Data Processing
- Embedding Generation
- ChromaDB Vector Database
- LangGraph Workflow
- Streamlit UI
- AI Generated Reports

## Tech Stack

- Python
- LangChain
- LangGraph
- ChromaDB
- ollama
- Streamlit
